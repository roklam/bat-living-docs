BAT Living Docs — branch layout
================================

v0.1.0 baseline (frozen)
  - Tag: v0.1.0
  - Branch: release/v0.1.0 (same commit as the tag)

Ongoing work (next iteration)
  - Branch: next (currently checked out after setup)
  - package.json version: 0.2.0

Windows packaging (electron-builder; installers land in release/ — ignored by git):
  npm run build         # compile renderer + main process only
  npm run clean:release # kill packaged app + delete release/ (also runs automatically before pack/dist)
  npm run pack          # unpacked app under release/win-unpacked (quick test)
  npm run dist          # NSIS setup.exe + portable .exe for x64 Windows

Unsigned local builds use signAndEditExecutable=false (avoids symlink issues with
winCodeSign on some Windows setups). Windows SmartScreen may still warn until
you publish a signed build with your own code-signing certificate.

Typical commands (run from this folder):
  git checkout release/v0.1.0   # read-only baseline; same as tag v0.1.0
  git checkout next             # continue feature work (installer, scans, APIs, …)
  git show v0.1.0             # inspect baseline commit
